Job Apply Agent

Source · Node.js, OpenAI JSON agents, LaTeX, local browser autofill

Job Apply Agent is a local assistant for job applications. The goal is not to submit applications automatically. The goal is to remove the repetitive work around searching, tailoring, drafting, and filling, while keeping the final decision visible.

What it does

  • Turns a plain-language search target into supported ATS searches.
  • Scores fit and skips roles with obvious mismatch signals.
  • Tailors a one-page LaTeX resume from source-backed bullets.
  • Drafts form answers from verified profile and wiki context.
  • Fills forms locally, without treating fill as submission.

How it is structured

The app runs as a local Node server with a small dashboard. The queue store owns application state. OpenAI workers return schema-validated JSON for search planning, match reasoning, resume choices, and answer drafts. Deterministic code handles gates like queue transitions, resume PDF validation, and submit confirmation.

Why the boundaries matter

Job applications mix automation-friendly work with personal judgment. This project keeps generated artifacts, local profile data, private resume content, and API keys out of git. It also keeps the browser autofill path separate from the LLM path, so filling a form is never confused with submitting one.
