Job Apply Agent

Job Apply Agent is a local, human-reviewed assistant for job applications. It coordinates ATS job discovery, fit scoring, LaTeX resume tailoring, form-answer drafting, and browser autofill while keeping final submission under explicit user control.

Project note

A local assistant for careful job applications

The project started from a simple tension: job applications are repetitive enough to benefit from automation, but personal enough that blind automation is the wrong answer. The system is designed as a local control room instead of a bot that disappears into the background.

The core loop is deliberately reviewable. A search planner turns a natural-language target into supported ATS searches, deterministic gates skip roles that do not fit, and OpenAI JSON agents prepare structured outputs for match reasoning, resume tailoring, and form answers. Queue state records what happened at each step.

Resume generation uses a LaTeX source file, keeps a truth ledger of selected bullets, compiles the tailored result, and validates that the PDF stays to one full page. Runtime data, generated artifacts, local profile details, and the private resume are ignored by git; the public repo includes a safe example resume template instead.

The autofill path is separated from the LLM path. A local Chrome bridge reads and fills forms, attaches the tailored resume, and leaves submission to explicit verification or a user click. That boundary is the important part: the tool helps with the grind, but it keeps the final action visible.
